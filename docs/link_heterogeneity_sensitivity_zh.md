# 链路异质性零样本敏感性实验

目的：检验既有 Full EGAT-DPOT 与拓扑 GCN checkpoint 在**不重训**时，对物理链路带宽和链路安全等级分布变化的泛化能力。

不变项：物理拓扑、节点及其属性、除 `bw/max_bw/security` 外的全部链路属性、验证集选择出的 checkpoint、冻结测试请求 `seed_20001`–`seed_20005`、路径算法、动作掩码、reward 和全部推理参数。

| 变体 | 改变内容 | 设计理由 |
| --- | --- | --- |
| `bw_hetero` | 60% 链路带宽取 40–55，40% 取 110–125 | 期望均值保持 75，与原始 50–100 均匀带宽一致，但方差增大。 |
| `security_hetero` | 链路安全等级以相等数量取 1 或 3 | 均值约为 2，与原始 1–3 均匀分布一致，但移除中间等级。 |
| `joint_hetero` | 同时采用上述两种变化 | 联合链路属性分布偏移。 |

每个物理网络变体在生成时写入 `manifest.json`，包括源网络/输出网络 SHA-256、属性统计和不变量检查。任何已有目录均拒绝覆盖。

这是零样本鲁棒性分析，不应把它写成“在新分布上重新训练后优于 GCN”。结果应报告为 Full EGAT 与 GCN 在每个变体上、同一冻结测试集的性能变化，并重点比较 LTA Time Cost、Time R2C、链路安全合规率与 LCB 可靠性指标。
